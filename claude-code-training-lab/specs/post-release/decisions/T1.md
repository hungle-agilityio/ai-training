# Decisions during build: T1 (#538)

| Question | Chosen | Rejected | Why | From |
|---|---|---|---|---|
| Where is the header set? | In `healthz` itself, on the response it returns | A middleware for every page | AC1 limits the change to `healthz`; no other view, URL or setting changes | build |
| A value with a line break inside (not at the ends)? | Keep AC1's rule: only `str.strip()`; Django refuses such a header | Drop the header unless the value is 7 to 40 hex characters | Render sets a 40-hex commit; a format filter is a rule the issue does not ask for (raised as the pull request's One concern) | build |
| How is the variable read? | `os.environ.get("RENDER_GIT_COMMIT", "").strip()` inside the function | A module constant or a setting | AC1 asks for a read on every request, not at import time | build |
