# Decisions during build: release-page T1 (#548)

| Decision | Chosen | Why |
|---|---|---|
| How the GitHub cases fake the origin URL | The fixture repositories keep their local `origin`; the fake `run` answers only `git remote get-url origin` with `https://github.com/acme/shop.git`, answers `gh` itself and passes every other call to the real `subprocess.run` | `release.py` fetches from and pushes to `origin`, so a real GitHub URL would reach the network (issue AC5) |
| Where the step runs | In `main`, after the `try` block that returns 1, before the plan is printed | A failed page must never turn into exit 1 (AC3) |
| `--notes-url ""` | Treated as not given: no link lines | An empty link is not a link |
| A notes file that cannot be written | The reason in the warning is the error name (for example `NotADirectoryError`) | Same rule as for `gh` that cannot run (issue, Build details) |
| Notes file path | `STATE_DIR / release-<tag>.md` made absolute | The warning's command must work from any folder |
