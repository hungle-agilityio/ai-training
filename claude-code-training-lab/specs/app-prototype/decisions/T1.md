# Decisions during build: T1 (#503)

| Question | Chosen | Rejected | Why | From |
|---|---|---|---|---|
| How does a design entry find its built screen? | By the step's name in result.json | By the step's position | The issue asks for "that step's `screenshot`", and the owner settled that a step without one shows `Build screenshot missing: <step>`; a stopped browser check may hold fewer steps than the spec | build |
| Is `capture_designs` called when no step has `"design"`? | No, `design_pairs` is `[]` without a call | Calling it and getting an empty list | AC3 says such a run writes `[]`; no browser work is needed for it | build |
| How does `build_report.py` reach `design_capture.py`? | It loads the file next to it by path, through a function named `capture_designs` | A plain `import design_capture` | The report script is also loaded by path (tests, the browser check), where its folder is not on the import path | build |
| What happens to a `"viewport"` that is not `<width>x<height>`? | 1280 by 800 is used | Stopping the report | AC5: the report is still written; the browser check has already refused a wrong size before this point | build |
| Which page reads the state ids? | A first page of the same context, closed before the first state is opened | Reading them on the first state's page | Each state must get a new page so nothing carries over (the owner's decision), and the ids are needed before any state is opened | build |
| Which steps get `Design not captured` after a Playwright error? | The step being captured and every step after it; steps already done keep their result | Every step | AC5 says "every remaining step" | build |
