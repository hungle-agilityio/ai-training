# Decisions during build: T1 (#493)

| Question | Chosen | Rejected | Why | From |
|---|---|---|---|---|
| With `app_dir` set to `.`, what does a `../x` pattern match? | Nothing: the pattern is used as written | Normalising the path | AC3 says nothing is put in front and names no other change; the repository root is then the app folder, so there is no folder above it | build |
| Does a file deleted on the branch count as changed? | Yes, it is listed and can match | Leaving deleted files out | AC3 takes the output of `git diff --name-only` as it is, and deleting a sensitive file (a migration) is a sensitive change | build |
| Which part of a failed git command goes in `review_level: <reason>`? | The git command's name and the first line of its error | The whole error text | AC4 asks for one line | build |
| Does the script run git when the config has no pattern? | Yes, so an unknown `--base` exits 2 with or without patterns | Printing `standard` without calling git | A wrong base is a wrong call either way; AC4 names no exception | build |
| Which config errors exit 2? | Any error while importing `flow_config.py` or loading the config | Only the config's own error class | AC4 says "the config cannot be loaded"; a missing reader file is that too | build |
