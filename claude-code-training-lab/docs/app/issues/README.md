# Issues

New issues are one markdown file each, grouped by type: `bugs/`, `features/` and `tasks/`; the six issues below are older four-file folders, kept as a learning record. The name is a short lowercase description; the branch uses the same words after the issue number (issue 1 has the branch `bug/1-dashboard-wrong-score`).

The issue number (ID) is the **GitHub issue number**, given when the issue is published with the `create-issue` skill. A draft is marked `draft` and has no ID yet. The first six issues were drafted with local numbers; the "Local no." column keeps those numbers because older commits and branches use them. When one is published, its GitHub number becomes the ID.
