# Issues

One folder per issue, grouped by type: `bugs/`, `features/` and `tasks/`. The folder name is a short lowercase description; the branch uses the same words after the number (issue 1 has the branch `bug/1-dashboard-wrong-score`).

The issue number is shared by bugs, features and tasks. The next issue gets the highest number below plus one.

| ID | Type | Folder | Title |
|---|---|---|---|
| 1 | Bug | `bugs/dashboard-wrong-score/` | Dashboard numbers look wrong |
| 2 | Bug | `bugs/dashboard-slow/` | Dashboard is very slow |
| 3 | Bug | `bugs/new-location-breaks-dashboard/` | New location breaks the dashboard |
| 4 | Feature | `features/filter-reviews/` | Filter reviews by good or bad |
| 5 | Bug | `bugs/reply-wrong-language/` | Reply drafts come out in the wrong language |
| 6 | Feature | `features/reviews-page/` | Reviews page to show all reviews |
