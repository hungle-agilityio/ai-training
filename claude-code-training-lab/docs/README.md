# Docs

Two kinds of documents, kept apart.

| Folder | About | Contains |
|---|---|---|
| `app/` | The demo app, ReviewRadar | `issues/` (bugs, features, tasks; one file per issue, index in `issues/README.md`), `templates/` (issue and README templates), project context |
| `learning/` | Learning Claude Code | `courses/` (Claude 101 notes), `journal/` (15 day journal), `exercises/` (role-play notes, step templates of the old four-file issues), `epics/` (work on the team's Claude Code practices), `capstone/` |

Rule of thumb: if it describes what the app should do or did, it goes in `app/`; if it records how we learn or adopt Claude Code, it goes in `learning/`.

`.claude/` holds the assistant's own settings and is not documentation.
