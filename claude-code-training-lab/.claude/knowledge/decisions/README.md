# Decisions (ADRs)

One file per decision: `ADR-001-short-title.md`, numbered in order. Write one for a non-trivial choice about architecture, tooling or a business rule.

```
# ADR-001: <title>

- Status: Proposed | Accepted | Superseded by ADR-00X
- Date: YYYY-MM-DD

## Context
## Decision
## Consequences
```
